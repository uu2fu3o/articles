什么是 WebGL 指纹？

WebGL 指纹是指通过浏览器中 WebGL（Web Graphics Library）接口暴露的硬件和软件信息，对用户设备进行唯一性标识的一种技术。它是一种浏览器指纹识别（Browser Fingerprinting）的方法，利用 WebGL 的渲染能力和设备特性生成独特的“指纹”，即使不依赖传统的标识符（如 Cookies）也能追踪用户。

WebGL 指纹的生成原理

WebGL 是基于 OpenGL 的 JavaScript API，允许浏览器通过 GPU 渲染 2D 和 3D 图形。指纹的生成主要依赖以下几个方面：

WebGL 参数

通过 WebGLRenderingContext 或 WebGL2RenderingContext 的 getParameter 方法，网站可以获取与 GPU 和驱动相关的参数。这些参数通常是 WebGL 指纹的核心：
GL_RENDERER：渲染器字符串，例如 "NVIDIA GeForce RTX 3080 OpenGL Engine"。
GL_VENDOR：GPU 供应商，例如 "NVIDIA Corporation"。
GL_VERSION：OpenGL 版本，例如 "4.6.0 NVIDIA 510.47.03"。
GL_SHADING_LANGUAGE_VERSION：着色语言版本，例如 "4.60 NVIDIA"。
UNMASKED_VENDOR_WEBGL 和 UNMASKED_RENDERER_WEBGL：未屏蔽的供应商和渲染器信息（更具体的硬件信息）。
其他参数：如支持的最大纹理大小（GL_MAX_TEXTURE_SIZE）、支持的扩展（getSupportedExtensions）等。
这些参数直接暴露了用户的 GPU 型号、驱动版本和操作系统信息，具有高度的唯一性。

扩展列表

通过 getSupportedExtensions 方法，浏览器返回支持的 WebGL 扩展列表（例如 ANGLE_instanced_arrays, EXT_texture_filter_anisotropic 等）。不同设备和驱动支持的扩展不同，这也是指纹的一部分。

渲染结果

WebGL 可以通过绘制特定的图形（例如三角形或纹理）并读取像素数据（通过 readPixels）生成指纹。由于不同 GPU 和驱动在渲染时的微小差异（如抗锯齿、抗噪点处理），即使硬件相同，渲染结果也可能略有不同。

WebGL 上下文类型

WebGL 1.0：由 canvas.getContext('webgl') 创建，兼容性更广。
WebGL 2.0：由 canvas.getContext('webgl2') 创建，支持更多特性，但在老旧设备上可能不可用。 指纹脚本可能会检测设备是否支持 WebGL 2.0，进一步增加唯一性。

随机WebGl

#include <cstdlib> // 用于 rand() 和 srand()
#include <ctime>   // 用于 time()

WebGLRenderingContextBase::getSupportedExtensions

std::optional<Vector<String>>
WebGLRenderingContextBase::getSupportedExtensions() {
  if (isContextLost())
    return std::nullopt;

  Vector<String> result;

  for (ExtensionTracker* tracker : extensions_) {
    if (ExtensionSupportedAndAllowed(tracker)) {
      result.push_back(tracker->ExtensionName());
    }
  }
  //uu2
  // 获取当前时间戳作为种子
  auto now = std::chrono::system_clock::now();
  auto timestamp = std::chrono::duration_cast<std::chrono::milliseconds>(
                       now.time_since_epoch())
                       .count();
  unsigned int seed = static_cast<unsigned int>(timestamp);

  // 使用时间戳初始化随机数生成器
  std::default_random_engine engine(seed);

  // 随机打乱 result 数组
  std::shuffle(result.begin(), result.end(), engine);
  return result;
}

WebGLRenderingContextBase::ReadPixelsHelper

修改getSupportedExtensions只能随机扩展的hash,无法随机图像的生成webgl的hash,找到对应函数进行修改

void WebGLRenderingContextBase::ReadPixelsHelper(GLint x,
                                                 GLint y,
                                                 GLsizei width,
                                                 GLsizei height,
                                                 GLenum format,
                                                 GLenum type,
                                                 DOMArrayBufferView* pixels,
                                                 int64_t offset) {
  if (isContextLost())
    return;
  // Due to WebGL's same-origin restrictions, it is not possible to
  // taint the origin using the WebGL API.
  DCHECK(Host()->OriginClean());
  // uu2
  // 初始化随机种子（仅第一次调用时执行）
  static bool seeded = false;
  if (!seeded) {
    std::srand(static_cast<unsigned>(std::time(nullptr)));
    seeded = true;
  }

  // 添加随机性到 width 和 height，范围为 ±5（可调整）
  width = width + (rand() % 11 - 5);    // -5 到 +5
  height = height + (rand() % 11 - 5);  // -5 到 +5

HTMLCanvasElement::toDataURL

为什么修改这里，toDataURL是最后返回绘制好图像的字符串数据的地方，是图像的base64数据
我们在数据后面随机添加空字符，达到随机的效果

String HTMLCanvasElement::toDataURL(const String& mime_type,
                                    const ScriptValue& quality_argument,
                                    ExceptionState& exception_state) const {
  if (ContextHasOpenLayers(context_)) {
    exception_state.ThrowDOMException(
        DOMExceptionCode::kInvalidStateError,
        "`toDataURL()` cannot be called with open layers.");
    return String();
  }

  if (!OriginClean()) {
    exception_state.ThrowSecurityError("Tainted canvases may not be exported.");
    return String();
  }

  double quality = kUndefinedQualityValue;
  if (!quality_argument.IsEmpty()) {
    v8::Local<v8::Value> v8_value = quality_argument.V8Value();
    if (v8_value->IsNumber())
      quality = v8_value.As<v8::Number>()->Value();
  }
  String data = ToDataURLInternal(mime_type, quality, kBackBuffer);
  TRACE_EVENT_INSTANT(
      TRACE_DISABLED_BY_DEFAULT("identifiability.high_entropy_api"),
      "CanvasReadback", "data_url", data.Utf8());
  //uu2
  // 初始化随机种子（仅第一次调用时执行）
  std::srand(std::time(nullptr));
  int randomNum = std::rand() % 100 + 1;
  std::string spaces(randomNum, ' ');
  data = data + String(spaces);
  return data;
}
